# Assignment-01-Who-Am-I-
Modern Web Application Development
Build Your First HTML Page:



In this assignment, you will create your very first webpage using basic HTML tags. The goal is to introduce yourself on a simple webpage. You will practice using the <h1> tag for a heading (your name) and <p> tags for paragraphs (your introduction).

This exercise will help you understand:

How to set up a basic HTML document
The difference between headings and paragraphs
How to display information in a structured way
By the end, you will have a personal introduction page that shows your name and a few sentences about yourself.
